## How I Work

- One note file per day: `days/day-XX-topic.md`
- Code for the day goes in `projects/day-XX/`
- Commit message format: `Day X: topic`
- Update the Daily Log table and progress badge after each day
- Notes are short and bullet-based, written for quick revision

## Run Locally

```bash
git clone https://github.com/eryxvaltor/120-days-frontend.git
cd 120-days-frontend/projects/day-05
```

Open `index.html` in a browser. No build step needed for the HTML + CSS phase.
