# Day 1: Introduction to the Web and HTML

## How the Web Works

|Term|Meaning|
|---|---|
|Client|The application requesting resources, such as a browser|
|Server|A computer that provides resources to clients|
|HTTP|Protocol used for communication between clients and servers|
|HTTPS|Secure HTTP communication using encryption|

## What is HTML?

HTML stands for **HyperText Markup Language**.

It defines the **structure and meaning** of webpage content. It is a markup language, not a programming language.

## HTML Element Structure

```html
<p>Hello World</p>
```

|Part|What it is|
|---|---|
|`<p>`|Opening tag|
|`Hello World`|Content|
|`</p>`|Closing tag|

Together, these form an **HTML element**.

## Basic HTML Document Structure

```html
<!DOCTYPE html>
<html>
  <head>
    <title>My Website</title>
  </head>
  <body>
    <h1>Hello World</h1>
    <p>My first webpage.</p>
  </body>
</html>
```

## Important HTML Elements

|Element|Purpose|
|---|---|
|`<html>`|Root element|
|`<head>`|Document metadata and resources|
|`<title>`|Browser tab title|
|`<body>`|Page content|
|`<h1>`|Main heading|
|`<h2>`|Second-level heading|
|`<p>`|Paragraph|

##  Concepts

|Concept|Meaning|
|---|---|
|Nesting|Placing one HTML element inside another|
|Browser|Interprets HTML and renders the webpage|
|Developer Tools|Lets you inspect a webpage's HTML, CSS and other resources|

Division of roles:

|Technology|Responsible for|
|---|---|
|HTML|Structure|
|CSS|Presentation|
|JavaScript|Behavior|
